# Assistance Mirror

Learn how to create symmetrical sketches quickly using the Mirror tool.
## Tap the Mirror in the Tool Menu
In the upper right Tool Menu, tap the Mirror icon. This will reveal three axes below it. Red for the
X-axis, green for the Y-axis, and blue for the Z-axis.

## Tap an Axis to Activate Mirror
Tap on any axis to activate the mirror for that axis. When the mirror is activated, a brief interface
will appear, showing the global axis in the respective color. You can activate multiple axes at the
same time.

## Tap the Mirror Again to Deactivate
To deactivate the mirror, tap the Mirror icon in the Tool Menu again. The previously used axes are
saved, so you can quickly reactivate the mirror with a single tap, making it very convenient.
