# Brushes Materials

Learn how to change materials and set patterns.
## Material Type
All curves drawn with Feather are 3D curves that respond to light. Use materials to add
depth and vibrancy to your work.
## Tap Render Mode Before Using Materials

Tap Render Mode icon in the Stage Panel to toggle the rendering method. Materials are displayed
accurately only in rendering mode.
You can change the lighting direction or add various effects in the Environment Tab.
## Shadeless
A basic material that does not respond to lighting or cast shadows. Patterns can be applied.

## Shaded
Responds to lighting and casts shadows. Patterns can be applied.

## Glow
Responds to the glow area, adding a glowing effect to the curves. Does not respond to lighting,
does not cast shadows, and patterns cannot be applied. You can adjust its intensity.
Learn more about Glow Area.

## Cutout
Responds to the background, making curves appear as the background color or image.
Learn more about World.
## Patterns
Patterns are procedurally generated textures. Push the boundaries of expression with
intricately woven patterns.

## Tap Pattern in the Color Panel
Select either the Shaded or Shadeless material, then tap "Pattern" at the bottom. Patterns cannot
be applied when using Glow or Cutout materials.

## Select a Pattern to Use
In the Pattern tab, tap the pattern you want to use. As of version 1.0, Feather supports five
patterns: from left to right, 'Dot', 'Line', 'Cross', 'Terrazzo', and 'Stippled Dot'.

## Tap and Slide to Adjust the Pattern
Slide sideways to adjust the pattern's intensity, angle, and contrast using the slider at the bottom.
