# Stage Panel Interface

Explore the basic layout and learn how to use the Stage Panel.
## Layout
The Stage Panel is a gateway to access the Group Tab, Resource Tab, and Environment Tab.
1. Add New Group
Add a new group. Available only in the Group Tab. Changes to Import in the Resource Tab.

2. Render Mode
Tap to toggle the render mode. In rendering mode, lights and shadows are cast, and various
effects can be configured. Patterns and materials are also applied.
Learn more about Materials.
3. Group Tab
Tab for adding, deleting, and managing groups.
Learn more about Group Tab.
4. Resource Tab
Tab for adding, deleting, and managing resources such as 3D Guides, imported images, and
imported 3D objects.
Learn more about Resource Tab.
5. Environment Tab
Tab for changing the background color, toggling grids, fog, and global axes. Filters such as Bloom,
Depth of Field, Grain, and Pixelation can be applied, and the Lighting tab allows you to set the
direction and intensity of the lights.
Learn more about Environment Tab.
