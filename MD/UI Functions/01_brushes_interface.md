# Brushes Interface

Explore the layout and usage of the brush panel.
## Layout
The left side of Feather is centered around the Brush Panel, with the Color Panel, History
Panel, and Brush Preset. Each panel provides efficient access to necessary functions.
## Brush Panel
1. Brush Type

Shows the current brush type and color. Tap or drag to change the brush type.
2. Active Color
Shows the current selected color. Tap or drag to change the color.
3. Brush Size Slider
Shows the current brush size. Slide up or down to adjust the brush size.
4. Opacity Slider
Shows the opacity of the selected brush. Slide up or down to adjust.
5. Pressure Sensitivity
Shows whether pressure sensitivity is enabled or disabled. Tap to toggle.
6. Injector
A tool that allows you to sample various properties of the brush.
7. Brush Preset
A panel where you can save and load your brush presets.
## Color Panel
8. Color Wheel
Adjust colors here. Spin the wheel to change the Hue (H), and use the square to adjust
saturation(S) and brightness(V).

9. Eyedropper
A tool to sample colors. The sampled color appears immediately in the color wheel.
10. Hex Code
Displays the hex code of the currently used color. Tap to input a hex code.
11. Material Type
Tap to change the material type. Learn more about Materials.
12. Patterns
Tap to change the pattern. Learn more about Patterns.
## History Panel
13. Undo and Redo
Undo or redo actions. Use the arrows to perform these functions.
## Brush Panel
Change brush types or quickly adjust size and opacity using the numpad.

## Change Brush Type
Use distinctive brushes to create your unique 3D sketches.
Tap the brush icon at the top of the Brush Panel to change brush types. Alternatively, tap and hold
the brush icon and drag up or down to quickly switch brushes. Each brush has unique
characteristics in size and shape. Try them out to see the differences.

## Tap and Drag Active Color to Change SV
Quickly and frequently adjust saturation(S) and brightness(V) using this gesture.
Tap and hold the active color icon in the brush panel, then drag up, down, left, or right to adjust
the current color's saturation and brightness. Drag left or right to adjust saturation and up or
down to adjust brightness. This gesture is useful for making subtle color changes while drawing.

## Tap Brush Slider to Use Numpad
Accuracy matters, not just quick adjustments.
Tap the brush size slider or opacity slider once to expand them. Use them for more precise
adjustments. The numpad for direct input will appear below the expanded slider. You can open or
close the numpad by pressing the numbers below the expanded slider. Brush size ranges from
1mm to 300mm, and opacity ranges from 0% to 100%.

## Tap Pressure Sensitivity
Adjust the intensity of the brush for more diverse expressions.
Tap to toggle pressure sensitivity on or off. When pressure sensitivity is enabled, the size, opacity,
or color of the brush adjusts based on the pressure applied with the pen.
## Injector
The injector is similar to the eyedropper but more advanced. It allows you to sample all
properties used on a previously drawn curve, including brush type, color, size, and opacity.

## Tap Injector in Brush Panel
Tap the Injector icon at the bottom of the brush panel. The icon turns black, indicating it’s ready
for use. Tap again to cancel. The Injector can only sample curves from the active group. Select the
group you want to activate from the Group Tab.

## Drag Curves to Sample Brush
While using the Injector, select or drag the pen over the curve you want to sample. This samples
the brush type, color, size, pressure, and opacity of that curve. You can check the brush properties
through the magnifier on the screen. If you only want to sample the color from a curve or
imported image, use the Eyedropper.
