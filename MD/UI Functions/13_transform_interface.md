# Transform Interface

Explore the basic layout and learn how to use Transform.
## Layout
The UI related to Transform only appears when you tap the Select tool or select a group or
resource from the Stage Panel.
## 2D Joystick
1. Move

Move the selected curve or resource freely.
2. Rotate
Rotate the selected curve or resource.
3. Free Scale
Freely scale the selected curve or resource.
4. Width Scale
Scale the selected curve or resource horizontally.
5. Height Scale
Scale the selected curve or resource vertically.
6. Lock 2D Joystick
Lock the 2D Joystick. When locked, you can only transform in restricted directions or values. Learn
more about Lock 2D Joystick.
7. Switch to 3D Joystick
Switch to the 3D Joystick.

## 3D Joystick
1. Move to X Axis
Move the selected curve or resource along the global X axis.
2. Move to Y Axis
Move the selected curve or resource along the global Y axis.
3. Move to Z Axis
Move the selected curve or resource along the global Z axis.
4. Rotate by X Axis

Rotate the selected curve or resource along the local X axis.
5. Rotate by Y Axis
Rotate the selected curve or resource along the local Y axis.
6. Rotate by Z Axis
Rotate the selected curve or resource along the local Z axis.
7. Free Rotate
Freely rotate around the center point of the curve or resource like a trackball.
