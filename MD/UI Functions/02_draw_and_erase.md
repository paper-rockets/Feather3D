# Brushes Draw and Erase

Learn how to draw curves and erase them.
## Draw and Paint
Draw or paint on the 3D Guide, imported reference images, or 3D models.
## Draw on 3D Guide
Drawing on a 3D Guide is one of the quickest ways to create 3D objects. Repeat drawing 3D
Guides and drawing on 3D Guides to complete your artwork quickly.

Tap "Draw" when a 3D Guide is present. Draw on the 3D Guide with your pen to create curves. The
curves will follow the selected brush type, color, size and opacity.
## Draw on Image
Import three-view or blueprint images and draw them as a 3D sketch.
If an imported image resource is in draw-on mode, you can draw on it. The image acts like a flat
3D Guide, and you cannot draw outside its boundaries.
Learn more about Import Image.

## Draw on 3D Model
Import a 3D model and draw on it. Using a reference model allows for faster 3D sketching.
If an imported 3D model resource is in draw-on mode, you can draw on it. The model acts like a
curved 3D Guide.
Learn more about Import 3D Model.
## Erase and Vaccum
You can’t always draw perfectly from the start. If you need to correct something, you can
erase it precisely or more aggressively.

## Erase
Tap the Eraser in the tool menu. Tap or drag with your pen to erase parts of the curve.
## Tips
The Eraser removes points from the center of the curve, not the surrounding geometry. If
you’ve drawn with a broad brush and the Eraser doesn’t touch the center, it may appear
as though it’s not erasing.

## Vaccum
The advantage of being bold is speed. Use the vacuum tool for more efficient erasing.
Tap the Eraser again in the tool menu to switch to the Vacuum tool. Tap or drag with your pen to
erase all curves it touches. This is useful for quickly erasing large areas.

## Isolate by 3D Guide
Define areas you don’t want to erase. Another way to use 3D guides.
Cover the curves you don’t want to erase with a 3D Guide. The eraser will not erase curves within
the guide. This is helpful for distinguishing between areas you want to keep and erase. It also
works for selecting curves; isolated areas by the 3D guide cannot be selected.
Learn more about Selection.
