# Extensions Clipboard

Explore the Clipboard layout and learn how to add image references and use them.
## Layout
The Clipboard is another workspace that includes numerous features.
1. Resize Handle
Resize the Clipboard's size and ratio.

2. Move Handle
Move the Clipboard's position.
3. Opacity Slider
Adjust the Clipboard's opacity.
4. Lock / Unlock Clipboard
Lock or unlock the Clipboard. When the Clipboard is locked, it cannot be moved or resized, and all
actions are blocked until it is unlocked.
5. Board
A board where you can view and adjust images.
6. Add New Image
Add a new image.
7. Next / Previous Image
Switch between images.
8. Options
Access various Clipboard options.
9. Import to Stage

Import the image currently on the board to the stage. The imported image will be removed from
the Clipboard.
10. Delete
Delete the image currently on the board.
## Actions
Freely move the Clipboard and adjust images to the optimal state for reference.
## Hold and Drag to Adjust Clipboard

Hold and drag the resize or move handles to adjust the size or position of the Clipboard. Move
the Clipboard to a desired location where you can reference the image without interference while
drawing.
## Tap and Slide to Adjust Opacity
Tap and slide the opacity slider left or right to adjust the opacity. Sliding left decreases
transparency, and sliding right increases it.

## Pinch to Zoom and Pan
Place two fingers on the board and pinch to zoom in or out or pan. This is useful when you want
to view a part of the image.

## Sample Color from Clipboard
Use the Eyedropper in the color panel to sample a color from the Clipboard image. You can
sample for background color in the Environment Tab.
Learn more about Eyedropper.

## Import Your Image to Stage
Tap Import to Stage to import the image from the board directly into the Stage Panel. The
imported image will be placed centered on the grid with a vertical orientation to the current view.
You can check the imported image in the Resource Tab.
