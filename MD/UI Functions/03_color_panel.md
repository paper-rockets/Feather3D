# Brushes Color

Learn how to change colors and sample colors using the eyedropper tool.
## Color Panel
Every 3D curve in Feather is born with color. Choose your desired colors freely and create
colorful 3D drawings.
## Open Color Panel

Tap the Active color in the Brush Panel on the left side of the screen to open the Color Panel. Tap it
again to close the Color Panel.
## Choose a Color
Tap and spin the color wheel to adjust the hue. Tap and drag within the square to adjust the
saturation and brightness. The currently selected color will appear as the Active Color and the
brush color. You can also adjust the color after drawing a curve by using the Select and Deselect.
## Eyedropper
Sample new colors from reference images or drawn curves

## Tap Eyedropper in Color Panel
Tap the Eyedropper on the right side of the Color Panel. When the Eyedropper turns black, it’s
ready to sample colors.

## Sample from Clipboard or Curves
You can sample new colors from the drawn curves or reference images in the clipboard. The curve
you want to sample from must be in the currently Active Group.
Learn more about the Clipboard.

## Tap Hex Code to Input
Tap the hex code to open the input pad for entering a hex code. After entering the hex code, tap
the confirm button to apply the new color.
